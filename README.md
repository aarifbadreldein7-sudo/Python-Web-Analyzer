# Python Web Analyzer

A simple Python tool for analyzing HTTP responses from websites.

## Features

* Check HTTP status code
* Display server information
* Detect content type
* Display content encoding
* Show content length
* Display the final URL after redirects
* Measure response time
* Handle connection errors and timeouts

## Requirements

* Python 3
* Requests

Install Requests:

```bash
pip install requests
```

## Usage

Run the program:

```bash
python main.py
```

Enter a website URL when prompted.

## Purpose

This project was created for learning Python, HTTP, and web security fundamentals.

Use this tool only on websites and systems you are authorized to test.
